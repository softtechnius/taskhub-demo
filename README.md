# TaskHub Terminal · dépôt de démonstration

Ce dépôt est **fictif**. Il sert d'exemple dans la vidéo et la [démo en ligne de TaskHub Terminal](https://taskhub.softtechnius.com/demo), une solution [SoftTechnius](https://softtechnius.com).

Il montre comment une tâche TaskHub se relie toute seule à son code. Ici, la tâche **KMALL-6 · Écran d'inscription** du projet fictif « Site Kinshasa Mall » de l'Agence Lumière :

1. Dans la tâche, TaskHub propose le nom de la branche : `feature/KMALL-6-ecran-d-inscription`.
2. La pull request dont le nom de branche ou le titre contient **KMALL-6** apparaît dans la tâche, avec ses commits.
3. Une fois la pull request fusionnée, le lead d'équipe peut valider la tâche.

Aucune donnée réelle : l'entreprise, les personnes et le projet sont inventés.
